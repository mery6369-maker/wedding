# 💍 감성 프리미엄 모바일 청첩장 웹 스튜디오 (v2.5)

본 제품은 서버 설치나 데이터베이스 구축 없이, 모바일 및 데스크톱 브라우저에서 즉시 열어 사용할 수 있는 **Zero-Server 모바일 청첩장 셀프 제작 솔루션**입니다.

---

## 🌟 주요 기능
1. **3가지 시그니처 커버 디자인**
   - 01. 듀오 프레임 (시그니처: 전신 메인 컷 + 디테일 컷 + 감각적 날짜 블록)
   - 02. 매거진 풀화면 (시네마틱 화보형 풀스크린 + 영문 세리프 타이포)
   - 03. 아치 & 갤러리 액자 (미니멀 화이트 여백 + 부드러운 아치 곡선)
2. **Pure 상태 시작 & 모바일 퍼스트 편집**
   - 불필요한 가상 인물 데이터를 한 번에 비우는 `Pure 상태 시작` 지원
   - 신랑·신부 및 양가 부모님 성함, 故 표기, 서열(장남/차녀), 혼주 연락처 연동
   - 세부 교통안내 (🅿️ 주차, 🚇 지하철, 🚌 버스) 및 네비게이션 자동 연동
3. **청첩장 표시 항목 자유 ON / OFF (섹션 설정)**
   - 초대글 & 혼주 정보, 달력 & D-Day, 갤러리, 오시는 길, 축의금 계좌, RSVP 참석 여부, 방명록, 공유 버튼을 신랑신부 취향에 맞게 자유롭게 켜고 끌 수 있습니다.
4. **실시간 축하 방명록 (Guestbook)**
   - 하객들이 실시간으로 축하 메시지를 남길 수 있는 인터랙티브 방명록 탑재 (비밀번호 삭제 지원)
5. **최대 20장 포토 갤러리 & 라이트박스**
   - 번호 표기 (①, ②, ③ ...) 및 스마트 캔버스 자동 리사이징 & 압축 (장당 15MB 제한)
   - 탭 시 고화질 풀스크린 라이트박스 확대 뷰어 지원
6. **새로워진 감성 BGM 플레이어**
   - 곡별 즉시 미리듣기 지원 (로맨틱 웨딩 피아노 & 커스텀 MP3 업로드)
   - 모바일 브라우저 자동 재생 정책(Autoplay Policy) 완벽 대응
   - 음량(볼륨) 조절 슬라이더 지원
7. **서버 유지비 0원 영구 링크 생성**
   - URL State 직렬화 방식으로 GitHub Pages나 무료 웹호스팅에 1초 배포 가능
   - 단독 완전체 `.html` 파일 백업 다운로드 기능 지원

## 🚀 빠른 시작 가이드

### 1. 로컬에서 바로 열기
- 압축을 푼 폴더에서 `index.html`을 더블 클릭하여 크롬(Chrome), 사파리(Safari), 엣지(Edge) 등의 브라우저로 엽니다.
- 브라우저 상에서 원하는 텍스트, 사진, 계좌번호, 오시는 길을 입력하고 [🚀 웹 링크 생성]을 누릅니다.

### 2. 무료 웹 호스팅 배포 (GitHub Pages 이용 시)
1. GitHub 계정 생성 후 새 저장소(Public Repository)를 만듭니다.
2. 압축 해제된 모든 파일(`index.html`, `styles.css`, `app.js`, `audio/` 등)을 저장소에 업로드합니다.
3. 저장소의 **Settings > Pages > Branch: main** 선택 후 Save를 클릭합니다.
4. 약 1분 후 `https://아이디.github.io/저장소명/` 주소로 영구 무료 모바일 청첩장이 오픈됩니다.

## 📁 파일 구성
- `index.html`: 청첩장 스튜디오 메인 마크업
- `styles.css`: 아이보리 브라이덜 감성 테마 및 모바일 반응형 스타일시트
- `app.js`: 데이터 바인딩, BGM 오디오 엔진, 갤러리 압축, URL 직렬화 엔진
- `audio/romantic_piano.mp3`: 상업적 사용 가능한 로맨틱 웨딩 피아노 음원
- `sample_*.jpg`: 기본 예시 웨딩 사진 에셋
